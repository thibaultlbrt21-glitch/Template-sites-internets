L'espace client n'a pas pu se charger

L'interface d'administration est chargée depuis un service externe (unpkg.com). Si vous êtes sur un réseau qui le bloque, essayez depuis une connexion mobile ou un autre réseau.

Si le problème persiste, la procédure d'installation complète est décrite dans le fichier ADMIN.md du site.
